# Проверка выпуска 1.0.0

Дата: 18 ноября 2026. Среда: Windows 11 x64, Python 3.14.10, PySide6 6.12.0.

- `pytest -q`: **30 passed**. Проверены поиск, раскладка, неточные совпадения,
  импорт без частичного сохранения, дубликаты, SQLite, избранное и история.
- UI-проверки используют Qt offscreen и подмену функции запуска: проверяют выбор,
  Enter, копирование результата, валидацию диалога и навигацию.
- `ruff check .`: замечаний нет.
- Просмотрены снимки реальных Qt-виджетов; исправлена загрузка шрифтов в offscreen.
- Создана Windows-сборка PyInstaller. `OrbitLauncher.exe --smoke --demo --data-dir ...`
  завершился с кодом **0**, создал отдельную тестовую базу.
- В обычном сеансе Windows проверены успешная регистрация и немедленная отмена
  Ctrl+Alt+Space через Win32 RegisterHotKey / UnregisterHotKey.
- При сборке выявлен конфликт ICU из окружения разработчика. Сценарий сборки исключает
  посторонние ICU DLL и использует системную ICU Windows. Исправленный EXE повторно проверен.

Ручное нажатие глобальной горячей клавиши в чужом приложении, поведение трея в разных
конфигурациях Windows и отдельная чистая Windows 10 VM не проверялись. CI-конфигурация
подготовлена для GitHub; удалённый запуск Actions не выполнялся.

Это проверки агента над новым проектом, созданным по прямому поручению пользователя.
Старые учебные программы не запускались.
