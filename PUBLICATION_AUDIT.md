# Проверка перед публикацией

Проверены исходники обоих проектов, правила Git, ZIP-архивы и wheel-пакет.
В исходной проверке было 78 файлов вне `.gitignore`. Содержимое найденных совпадений
не выводилось в отчёт как секретные значения.

## Результат

- Рабочие API-токены, приватные ключи, личные пароли и локальные пути пользователя
  в исходниках для публикации не обнаружены.
- Пароли в `demo.py` и тестах — специально заданные публичные демонстрационные значения.
  Они не являются паролем рабочего кабинета, создаваемого пользователем.
- URL с логином и паролем в тестах — намеренно некорректные примеры проверки валидации.
- Базы и сессионные ключи исключены из Git и исходных архивов. Их содержимое не читалось.
- Проекты на момент проверки не имели отслеживаемых файлов или коммитов в локальном
  родительском репозитории. GitHub и возможные внешние репозитории не проверялись.
- Проверены известные сигнатуры ключей, credential-URL, константы паролей и персональные пути.

В бинарной сборке Orbit найдены служебные строки в Qt, похожие на сигнатуры ключей и пути.
Эти файлы побайтово совпадают с установленными библиотеками поставщика; полного PEM-ключа
или пути локального пользователя в отмеченных библиотеках не обнаружено.
Снимки UI содержат демонстрационные данные. Локальные адреса `127.0.0.1` и пример
`C:\Projects` не дают внешнего доступа к компьютеру.

## Что исправлено

- Добавлены исключения `.env.*`, приватных ключей, копий баз, журналов и экспортов.
- В Linklane дополнены исключения Docker build context.
- Упаковка теперь выбирает явно разрешённые исходные файлы и отвергает секретные имена,
  рабочие каталоги и символические ссылки / junctions на любом уровне.
- 15 тестов упаковки в каждом проекте прошли. Git подтвердил исключение 16 контрольных путей.
- Архивы исходников пересобраны после исправлений.

## Как публиковать

Используйте архив `*-source.zip` или Git с этим `.gitignore`.
Не загружайте всю локальную папку вручную через браузер: при таком способе GitHub
не применяет ваш `.gitignore` к выбранным файлам.
Не добавляйте исключённые файлы через `git add -f`.

Проверка относится к утечке данных при публикации. Это не независимый аудит всех
уязвимостей приложения или его зависимостей и не гарантия отсутствия любых ошибок.
